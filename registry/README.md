# Video.js source registry

This directory contains the generated React and HTML source registry in Tailwind and vanilla CSS variants.

Run `pnpm generate:registry` after changing canonical Skin source, artifacts, lowering, icons, or style generation. Run `pnpm check:registry` to verify committed output has not drifted.

The `default-video-controls` item is a partial core-controls milestone, not the final released Default Skin.
