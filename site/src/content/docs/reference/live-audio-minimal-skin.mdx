The minimal skin of the live audio preset: the same player with a smaller control set and a Live button in place of time controls. <DocsLink slug="reference/live-audio-skin">LiveAudioSkin</DocsLink> is the same preset's other variant. See <DocsLink slug="concepts/skins">Skins</DocsLink> for how packaged skins work and <DocsLink slug="concepts/presets">Presets</DocsLink> for what the live audio preset ships.

## Import

<SkinImports preset="live-audio" react="MinimalLiveAudioSkin" minimal />

## Usage

The skin nests between the player and the media element and renders its controls around the media it wraps.

<FrameworkCase frameworks={["react"]}>
```tsx
<LiveAudioPlayer>
  <MinimalLiveAudioSkin>
    <Audio src="live.m3u8" />
  </MinimalLiveAudioSkin>
</LiveAudioPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<live-audio-player>
  <live-audio-minimal-skin>
    <audio src="live.m3u8"></audio>
  </live-audio-minimal-skin>
</live-audio-player>
```
</FrameworkCase>

## Styling

Packaged skins style themselves and expose four CSS custom properties: `--media-accent-color`, `--media-accent-text-color`, `--media-border-radius`, and `--media-scale-unit`. Everything else inside the skin is private and may change between releases. <DocsLink slug="how-to/customize-skins">Customize skins</DocsLink> covers the properties and the ejection path when you need deeper changes.
