`createPlayer` builds a custom-element class from the features your player needs. It returns `PlayerElement`, a `PlayerController` already bound to that player, and the typed `playerContext`.

```ts title="player.ts"
import { createPlayer, UIElement, selectPlayback, videoFeatures } from '@videojs/html';

const { PlayerElement: VideoPlayerElement, PlayerController } = createPlayer({
  features: videoFeatures,
});

customElements.define('video-player', VideoPlayerElement);

class PlayButton extends UIElement {
  #playback = new PlayerController(this, selectPlayback);
}
```

The returned `PlayerElement` owns the store and makes it available to descendants. Use the shared `ContainerElement` or import `@videojs/html/ui/container` to register `<media-container>` when you build a custom layout. The container is the visual and fullscreen boundary; the player itself defaults to `display: contents`.

For standard video, audio, live, and background players, prefer the preset entry points. They export a named player element and a typed `PlayerController`, and register the player and default skin with one import:

```ts
import { PlayerController, VideoPlayerElement } from '@videojs/html/video';
```
