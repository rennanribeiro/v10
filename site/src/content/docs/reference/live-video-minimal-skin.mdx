The minimal skin of the live video preset: the same player with a smaller control set and a Live button in place of time controls. <DocsLink slug="reference/live-video-skin">LiveVideoSkin</DocsLink> is the same preset's other variant. See <DocsLink slug="concepts/skins">Skins</DocsLink> for how packaged skins work and <DocsLink slug="concepts/presets">Presets</DocsLink> for what the live video preset ships.

## Import

<SkinImports preset="live-video" react="MinimalLiveVideoSkin" minimal />

## Usage

The skin nests between the player and the media element and renders its controls around the media it wraps.

<FrameworkCase frameworks={["react"]}>
```tsx
<LiveVideoPlayer>
  <MinimalLiveVideoSkin>
    <Video src="live.m3u8" />
  </MinimalLiveVideoSkin>
</LiveVideoPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<live-video-player>
  <live-video-minimal-skin>
    <video src="live.m3u8"></video>
  </live-video-minimal-skin>
</live-video-player>
```
</FrameworkCase>

## Poster

<FrameworkCase frameworks={["react"]}>
The skin renders a poster image before playback starts. Pass `renderPoster` to replace it with your own component.
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
The skin renders a poster image before playback starts. An element with `slot="poster"` replaces it.
</FrameworkCase>

See <DocsLink slug="how-to/add-a-poster-and-loading-placeholder">Add a poster and loading placeholder</DocsLink> for complete examples.

## Styling

Packaged skins style themselves and expose four CSS custom properties: `--media-accent-color`, `--media-accent-text-color`, `--media-border-radius`, and `--media-scale-unit`. Everything else inside the skin is private and may change between releases. <DocsLink slug="how-to/customize-skins">Customize skins</DocsLink> covers the properties and the ejection path when you need deeper changes.
