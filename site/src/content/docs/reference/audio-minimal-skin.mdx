The minimal skin of the audio preset: the same player with a smaller control set. <DocsLink slug="reference/audio-skin">AudioSkin</DocsLink> is the same preset's other variant. See <DocsLink slug="concepts/skins">Skins</DocsLink> for how packaged skins work and <DocsLink slug="concepts/presets">Presets</DocsLink> for what the audio preset ships.

## Import

<SkinImports preset="audio" react="MinimalAudioSkin" minimal />

## Usage

The skin nests between the player and the media element and renders its controls around the media it wraps.

<FrameworkCase frameworks={["react"]}>
```tsx
<AudioPlayer>
  <MinimalAudioSkin>
    <Audio src="audio.mp3" />
  </MinimalAudioSkin>
</AudioPlayer>
```
</FrameworkCase>

<FrameworkCase frameworks={["html"]}>
```html
<audio-player>
  <audio-minimal-skin>
    <audio src="audio.mp3"></audio>
  </audio-minimal-skin>
</audio-player>
```
</FrameworkCase>

## Styling

Packaged skins style themselves and expose four CSS custom properties: `--media-accent-color`, `--media-accent-text-color`, `--media-border-radius`, and `--media-scale-unit`. Everything else inside the skin is private and may change between releases. <DocsLink slug="how-to/customize-skins">Customize skins</DocsLink> covers the properties and the ejection path when you need deeper changes.
